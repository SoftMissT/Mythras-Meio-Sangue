## 🇧🇷 Português

### O que é este projeto?

**Mythras: Meio-Sangue** é uma adaptação não oficial do sistema [Mythras](http://thedesignmechanism.com) para o [Foundry Virtual Tabletop](https://foundryvtt.com), com foco na comunidade brasileira de RPG de mesa.

Este repositório é um fork do excelente trabalho desenvolvido por [kp-systems](https://gitlab.com/kp-systems/mythras) e colaboradores, traduzido e adaptado para o português do Brasil, com possíveis ajustes de regras e conteúdo voltados ao cenário **Meio-Sangue** e à experiência de jogo local.

## 🇺🇸 English

### What is this project?

**Mythras: Meio-Sangue** is an unofficial fan adaptation of the [Mythras](http://thedesignmechanism.com) system for [Foundry Virtual Tabletop](https://foundryvtt.com), focused on the Brazilian tabletop RPG community.

This repository is a fork of the excellent work developed by [kp-systems](https://gitlab.com/kp-systems/mythras) and contributors, translated and adapted into Brazilian Portuguese, with potential rule and content adjustments aimed at the **Meio-Sangue** setting and local play experience.
